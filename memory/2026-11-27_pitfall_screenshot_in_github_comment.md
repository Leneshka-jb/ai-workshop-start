[2026-11-27] [Pitfall] To post a screenshot in a GitHub issue/PR comment: `gh` cannot upload images, so commit the PNG to a side branch with `gh api -X PUT repos/<owner>/<repo>/contents/<path>` (base64 content, `branch`), then embed `https://github.com/<owner>/<repo>/blob/<commit-sha>/<path>?raw=true`. To screenshot the web view with other data, run `./skill-atlas serve <port>` (port is positional, not `--port`) and let Playwright `page.route('**/api/clusters', ...)` serve the JSON.
